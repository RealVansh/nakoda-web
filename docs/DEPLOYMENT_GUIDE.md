# Deployment Guide — Nakoda Web

## 1. Overview
Nakoda Web uses a modern serverless stack:
- **Vercel**: Edge-network hosting, Next.js optimization.
- **Neon**: Serverless PostgreSQL database.
- **Cloudinary**: Media CDN and image transformations.
- **GitHub**: Source control and CI/CD integration.

## 2. Prerequisites
- Node.js 18+ (LTS)
- A GitHub account.
- Vercel, Neon, and Cloudinary accounts.

## 3. Local Development Setup
Clone the repository and install dependencies:
```bash
git clone https://github.com/your-org/nakoda-web.git
cd nakoda-web
npm install
```

Configure environment variables:
```bash
cp .env.example .env.local
```
Fill out the variables in `.env.local` (see Authentication & Security for a full list).

Set up the database:
```bash
npx prisma generate
npx prisma migrate dev --name init
npx prisma db seed
npm run dev
```

## 4. Neon PostgreSQL Setup
1. Create a project in Neon.tech, selecting a region near your primary user base.
2. Under "Connection Details", copy both the **pooled connection string** and the **direct connection string**.
3. The pooled string goes into `DATABASE_URL`. The direct string goes into `DIRECT_DATABASE_URL` (vital for Prisma migrations).

## 5. Cloudinary Setup
1. Sign up for Cloudinary.
2. In the dashboard, secure your `cloud_name`, `api_key`, and `api_secret`.
3. Create a folder `nakoda-web` in the Media Library. Sub-folders like `products/` will be dynamically generated by the upload scripts if they don't exist, but you can configure upload presets if desired.

## 6. Vercel Deployment

### Step 1: Connect Repository
Go to Vercel.com, click "Add New...", select Project, and import your `nakoda-web` GitHub repository.

### Step 2: Configure Build Settings
Vercel automatically detects Next.js.
- **Build Command**: `prisma generate && prisma migrate deploy && next build`
- **Install Command**: `npm install`

### Step 3: Environment Variables
Add all the variables from your `.env.local`. Be absolutely certain to add the Neon production URLs and the `AUTH_SECRET` (generate a secure random 32-character string for production).

### Step 4: Deploy
Click Deploy. Vercel will run the Prisma migrations against the remote Neon database and build the Next.js app. 

### Step 5: Post-Deployment Seeding
Once the deployment succeeds, locally run the seed script targeted at the production database to create the primary admin account:
```bash
# Export the production direct URL locally temporarily
export DATABASE_URL="postgresql://production-url..."
npx prisma db seed
```

## 7. CI/CD Pipeline
Vercel handles CI/CD out-of-the-box.
- **Production**: Pushing to the `main` branch automatically builds and deploys to the main domain.
- **Preview**: Pushing a new branch or creating a Pull Request generates a unique ephemeral URL to test the features before merging.

## 8. Database Migrations in Production
To alter the database schema over time:
1. Make changes to `prisma/schema.prisma` locally.
2. Run `npx prisma migrate dev --name describe-change`.
3. Commit the generated SQL files in the `prisma/migrations` folder to Git.
4. Merge to `main`. Vercel will run `prisma migrate deploy` during the build step, applying the SQL securely to the Neon database without dropping data.

## 9. Production Checklist
- [ ] Are Vercel Environment Variables configured?
- [ ] Is the custom domain (e.g., `nakoda.com`) connected via CNAME?
- [ ] Did `prisma migrate deploy` run successfully in the Vercel Build Logs?
- [ ] Did you run the seed script to generate the Admin login?
- [ ] Did you configure the `NEXT_PUBLIC_WHATSAPP_NUMBER`?
- [ ] Have you tested the Cloudinary image upload on the production deployment to ensure CORS and Secrets are valid?
- [ ] Did you check Google PageSpeed Insights to verify performance?
